🚀 INSTRUCCIONES PARA EJECUTAR EL SERVIDOR

1. Instalar Node.js (si no lo tienes):
   - Descarga desde: https://nodejs.org/
   - Instala la versión LTS

2. Abrir terminal en la carpeta del proyecto:
   - Abre PowerShell o CMD
   - Navega a: d:\velatron4\Nueva carpeta\Velatron\commic

3. Instalar dependencias:
   npm install

4. Iniciar el servidor:
   npm start

5. Abrir en el navegador:
   http://localhost:3000/admin.html

El servidor creará las carpetas automáticamente en:
comics/[nombre-comic]/[temporada]/

¡Listo! Ahora puedes subir cómics desde el navegador.
